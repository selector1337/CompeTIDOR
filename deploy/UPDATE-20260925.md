# Atualização de 25/09/2026

Esta versão inclui Metas de Venda, conferência mensal por conta, preservação de
totais em gravações concorrentes, validação de paginação dos pedidos, correção da
tarja de preços e uma verificação leve de disponibilidade do servidor.

## Instalação

Faça primeiro o backup habitual dos dados da aplicação. Depois de disponibilizar
esta versão no repositório usado pelo servidor:

```sh
cd /opt/competidor
sudo git pull --ff-only
sudo systemctl restart competidor
curl --fail --max-time 15 http://127.0.0.1:8770/api/live
```

Prossiga somente se o último comando retornar `"ok":true`. O arquivo novo
`public/sales-goals.js` deve estar presente junto com server.py, app.js, index.html
e styles.css atualizados.

O monitor instalado fora do repositório também precisa ser atualizado. Apenas
`git pull` não substitui `/usr/local/sbin/competidor-healthcheck`:

```sh
sudo install -m 0755 deploy/competidor-healthcheck.sh /usr/local/sbin/competidor-healthcheck
sudo systemctl start competidor-healthcheck.service
sudo journalctl -u competidor-healthcheck.service -n 15 --no-pager
sudo systemctl status competidor-healthcheck.timer --no-pager
```

Não é necessário alterar limites de RAM nem substituir a configuração HTTPS do
Nginx para esta versão. Mantenha o `keepalive_timeout 15s` no upstream, conforme a
atualização anterior. O monitor passa a consultar `/api/live`, sem ler catálogo
nem esperar bloqueios das tarefas. `/api/health` continua disponível para
diagnóstico detalhado. O parâmetro opcional do monitor é agora
`COMPETIDOR_LIVENESS_URL`; o antigo `COMPETIDOR_HEALTH_URL` não é usado.

Atualize o navegador com Ctrl+F5.

## Conferir faturamento e cadastrar metas

Abra **Metas de Venda**, escolha o mês e clique em **Atualizar vendas**. A consulta
confere todas as contas conectadas com a API oficial, atualiza os totais mensais
por conta e os dados analíticos diários. Expanda **Vendas por conta e última
atualização** para comparar os valores. Se alguma conta falhar, a mensagem será
exibida; não considere o período totalmente conferido até todas concluírem.
Reabra o Dashboard para carregar os valores atualizados.

Use o mesmo horário, mês, contas e critério nos dois integradores: esta aplicação
contabiliza pedidos não cancelados/inválidos com valor positivo, pelo mês de
criação em America/Sao_Paulo, sem somar frete ao faturamento dos produtos. A
diferença informada de 18 pedidos/R$ 9.935,30 ainda precisa ser conferida com os
dados reais após instalar; os números do outro integrador não são impostos.

As metas são quantidades por SKU, somadas entre contas. Cadastre os valores e
clique em **Salvar metas**. No novo mês as metas são herdadas e o progresso
recomeça; o seletor de mês permite consultar o histórico. Excel e PDF respeitam
os filtros e exportam todos os resultados filtrados, não apenas a página visível.
Salve alterações antes de exportar. A sincronização normal das contas também
atualiza as vendas nas metas; não depende de deixar o menu aberto.

## Acompanhar estabilidade

Os logs fornecidos mostram reinícios disparados pelo monitor após três falhas
de saúde. Esta versão elimina a espera por bloqueios de negócio nessa verificação
e evita várias construções simultâneas da resposta grande do catálogo. Se houver
nova falha, o monitor registra o código e motivo do curl antes do reinício:

```sh
sudo journalctl -t competidor-healthcheck --since '1 hour ago' --no-pager
sudo journalctl -u competidor --since '1 hour ago' --no-pager
sudo tail -n 40 /var/log/nginx/error.log
```

Testes locais não substituem a observação sob a carga real do servidor. Aumentar
RAM permitida, sozinho, não corrige interrupções causadas pelo monitor.
