# Preços automáticos: fluxo contínuo e evolução de preços

O preço não volta mais ao original quando a meta é atingida ou o mês muda. A regra continua usando o preço atual, o intervalo configurado, a pausa após vendas e os limites de preço/margem. A virada do mês não reinicia o relógio da regra. Apenas o comando manual **Restaurar preços e desativar**, com confirmação, restaura o preço original.

Em **Metas de venda → Preços automáticos → Acompanhamento dos preços**, cada anúncio mostra:

- Preço original registrado.
- Último preço consultado/confirmado e data da consulta/confirmação.
- Redução acumulada em reais e porcentagem (ou aumento, caso o valor tenha subido).
- Preço pendente, resultado, envios e próxima conferência prevista.

Cada novo evento guarda também o original, o preço consultado/confirmado e a redução acumulada naquele momento. Valores pendentes não são tratados como aplicados. O acompanhamento não faz uma consulta em tempo real ao Mercado Livre ao abrir a tela; exibe os valores e horários registrados pelo processamento. Campos novos não são reconstruídos em eventos antigos.

Regras, preços originais e histórico existentes são preservados. Não apague `goal_pricing.json`. Regras desativadas continuam desativadas. Se a versão anterior já tiver restaurado algum preço, esta atualização não desfaz retroativamente aquela alteração.

Após disponibilizar esta versão no repositório, atualize no servidor:

```bash
cd /opt/competidor
git pull --ff-only
sudo systemctl restart competidor
curl --fail --max-time 10 http://127.0.0.1:8770/api/live
```

Depois, recarregue o navegador com Ctrl+F5. Se o Git apontar alterações locais, preserve-as antes de atualizar; não use reset destrutivo. Esta alteração não exige reinstalar o serviço auxiliar de recuperação já configurado. Para a primeira instalação desse auxiliar, consulte `deploy/UPDATE-20261019.md`.
